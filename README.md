# PulsR

Transportation management for dispatch, fleet operations, routing and fuel planning.

PulsR currently supports AMF Carrier's daily operations with TorqueAI as the active
dispatch source. The technical project name is `pulsartms`; carrier records remain
unchanged. The new cloud project is prepared, but production has not switched to it.
